# DEPRECATED – Architecture Sketch

This file described an earlier version of the Smart Energy retraining API where
both a baseline dataset and a full dataset snapshot were downloaded from MinIO on
each retraining call. That architecture is no longer in use.

The current deployed architecture uses a local base dataset on disk plus a small
appended-rows delta CSV downloaded from MinIO.

For the accurate, up-to-date description of the deployed API see:

    docs/retraining-api-current-state.md
